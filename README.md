## Entregables CAF

Este repositorio contiene los trabajos prácticos desarrollados en el marco de la asignatura de Machine Learning. Los entregables abordan temáticas clave como el análisis de métodos de ensamblado y auxiliares en aprendizaje automático, así como la implementación y evaluación de clasificadores multiclase. Cada trabajo incluye el desarrollo teórico y práctico de los conceptos, aplicando técnicas actuales para la resolución de problemas reales.
