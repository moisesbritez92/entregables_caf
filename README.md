## Entregables CAF

Este repositorio contiene los trabajos prácticos desarrollados en el marco de la asignatura de Machine Learning. Los entregables abordan temáticas clave como el análisis de métodos de ensamblado y auxiliares en aprendizaje automático, así como la implementación y evaluación de clasificadores multiclase. Cada trabajo incluye el desarrollo teórico y práctico de los conceptos, aplicando técnicas actuales para la resolución de problemas reales.

## 🤖 Custom Agents

Este repositorio incluye **agentes especializados** para revisión de trabajos:

### Entregable2 Reviewer Agent
**Ubicación**: `.github/agents/entregable2_reviewer.md`

Un revisor experto especializado en análisis de clasificadores multiclase basados en datos radar. Revisa salidas de R y proporciona retroalimentación estructurada sobre:
- Preprocesamiento y etiquetado de datos
- Análisis estadístico (RCS, tests de significancia)
- Métricas de rendimiento (AP/mAP)
- Análisis espacial (distancia y azimut)
- Selección de umbrales y generalización

**Documentación**:
- Guía de uso: `Entregable2/AGENT_USAGE_GUIDE.md`
- Referencia rápida: `Entregable2/AGENT_QUICK_REFERENCE.md`
- Ejemplo: `Entregable2/EXAMPLE_AGENT_REVIEW.md`

**Cómo usar**: Ejecuta tu análisis en R, captura las salidas de consola, y solicita una revisión usando el agente. Recibirás retroalimentación experta sin necesidad de re-ejecutar experimentos.
